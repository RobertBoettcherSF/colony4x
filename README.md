Colony4X

A clean-room, browser-based turn-based 4X game. All names, text and graphics are original. Mechanics are loosely inspired by the classic genre of alien-planet colonisation games.

## Play

- **Live:** [robertboettchersf.github.io/colony4x](https://robertboettchersf.github.io/colony4x/)

- **Offline:** open `index.html` in a browser (GNOME Web, Firefox, Chrome).

Press `?` in game for controls. F9 saves `col-feedback.json` for feedback.

## Contents

- `index.html`, `game.js`, `ui.js`, `style.css` — the game

- `play.py` — optional local live-log server

- `docs/CONCEPTS.md` — design notes
